# Payment Automation Framework & Study Notes

Este repositório é o meu projeto central de estudo técnico e aprendizado contínuo para Automação de Testes de API, utilizando **Playwright** e **TypeScript**.

## Estrutura do Projeto

- **`/` (Raiz)**: Contém o framework de automação em si (Playwright, Node.js, TypeScript). É aqui que os testes de API (como os da pasta `/tests`) rodam.
- **`/docs`**: O "Guia Definitivo" em PDF e HTML, além das descrições detalhadas de todas as Fases do curso (em Markdown, na pasta `/docs/fases`).
  - Para rodar o servidor da documentação: `npx live-server ./docs`
- **`/scripts`**: Scripts utilitários de apoio ao estudo (ex: `generate_course.py`).

## Como rodar os testes

```bash
npm install
npm test
```
